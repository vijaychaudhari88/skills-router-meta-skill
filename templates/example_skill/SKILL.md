# Example Feature Skill

## Overview
This is a reference example demonstrating how to structure custom project skills with YAML frontmatter for instant, token-efficient discovery.

## Usage Guidelines
- Keep the first 15 lines limited to YAML frontmatter (`name` and `description`).
- Specify concrete "Use when..." clauses in the description to assist Stage A and Stage B router matching.
- Define optional rich metadata in an adjacent `manifest.json`.
